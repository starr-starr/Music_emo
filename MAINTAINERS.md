# Maintenance plan

Music_emo is maintained by the repository owner, **starr-starr**.

## Current maintenance scope

- Review reproducible bug reports and focused pull requests.
- Keep the production build working on the supported Node.js version.
- Document API setup, third-party boundaries, and security-reporting expectations.
- Review dependency updates before merging them.

## Near-term priorities

1. Replace or document every demonstration asset whose redistribution rights are unclear.
2. Make the API contract explicit and provide a local mock or compatible development server.
3. Reduce the existing ESLint warning backlog without relaxing project standards.
4. Add user-visible error states for unavailable API services.

Issues and pull requests are the public record for maintenance work. This plan is intentionally modest: it describes the current project rather than promising release cadence or support levels that cannot yet be sustained.
